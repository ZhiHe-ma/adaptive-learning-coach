# Sources and third-party notices

The learning workflow draws on ideas from [mattpocock/skills](https://github.com/mattpocock/skills). Relevant guidance has been paraphrased and reorganized; the upstream repository is not a runtime dependency.

| Upstream skill | Design influence |
|---|---|
| [teach](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md) | Goal-directed practice and feedback |
| [wait-what](https://github.com/mattpocock/skills/blob/main/skills/productivity/wait-what/SKILL.md) | Re-explanation when understanding breaks down |
| [diagnosing-bugs](https://github.com/mattpocock/skills/blob/main/skills/engineering/diagnosing-bugs/SKILL.md) | Reproduction, hypotheses and discriminating evidence |
| [writing-for-agents](https://github.com/mattpocock/skills/blob/main/skills/productivity/writing-for-agents/SKILL.md) | Progressive disclosure and explicit reference triggers |
| [handoff](https://github.com/mattpocock/skills/blob/main/skills/productivity/handoff/SKILL.md) | Compact continuation state and references to existing artifacts |
| [domain-modeling](https://github.com/mattpocock/skills/blob/main/skills/engineering/domain-modeling/SKILL.md) | Consistent terminology and boundary examples |
| [tdd](https://github.com/mattpocock/skills/blob/main/skills/engineering/tdd/SKILL.md) | Behavior-focused tests and vertical slices |
| [code-review](https://github.com/mattpocock/skills/blob/main/skills/engineering/code-review/SKILL.md) | Separate specification and quality review |
| [codebase-design](https://github.com/mattpocock/skills/blob/main/skills/engineering/codebase-design/SKILL.md) | Small interfaces and deep modules |
