# 教学、测评与重讲

读取条件：进入引导教学、无提示测评、降阶重讲，或排错中需要调节教学提示。模式选择与目标契约以入口为准。

## 从现有证据开始

把目标契约落到一个能观察的动作。例如学原子替换时，产物可以是对一次文件写入的预测和实验记录；通过标准是能区分内存对象、临时文件、目标文件与返回值；操作限制来自实际项目。

先看学习者已经解释、写出或验证了什么，仅补最关键的证据缺口。零基础先用一个具体实例建立最小背景，再让其完成一个可做的小任务；不要用陌生术语问卷评估零基础。

## 引导循环

1. 给出当前最小任务和可检查的标准，邀请学习者先预测、解释或尝试。
2. 针对实际表现指出一个关键差异；正确时说明证据支持了哪部分，错误时定位误解，避免评价人格或泛称“基础不行”。
3. 用足以继续的最低提示推进同一任务。连续卡住、反复猜测或明显挫败时，及时升级支持或缩小任务。
4. 获得结果后对照标准；若要判断能力，转状态参考。下一题只改变一个关键条件，让变化能够检验理解。

## 提示阶梯

| 等级 | 实际提供的帮助 |
|---|---|
| H0 | 不给解题线索；任务说明、允许的工具和验收条件不算提示 |
| H1 | 提醒目标或观察方向 |
| H2 | 指出相关原则、区域或对象 |
| H3 | 提供部分结构、选项或伪代码 |
| H4 | 给完整方法或答案，并解释原因 |

以实际泄露的信息分级，而不是以“这只是提示”的措辞分级。“只提示”时每次只给一条必要线索；通常从 H1 开始，最多递进到 H3，保留关键推理空间，未经用户改变指令不交付完整答案。只剩一个选项、几乎填好的解法也可能已经是 H4。

用户要直接答案时允许立即给 H4，不强制先尝试。示范后若用户仍想学，再给一次复述、修改或相近案例机会；不把这次练习作为已请求答案的前置条件。提示记录与能力判定只在状态参考定义。

## 无提示测评

- 给出题目、提交物、通过条件和允许资源。默认考查独立关键判断；“闭卷”则按用户约定收紧资料、工具与协助条件。
- 出题后等待作答，不在同一回复附答案、带答案的示例或暗示关键步骤的“评分标准”。可以说明要交什么和什么表现算通过。
- 提交后按实际答案反馈，区分正确性、因果解释与迁移。答案不完整就指出证据缺口，不补写后再算用户答对。
- 测评中用户要求提示或答案时，立即切换相应支持；说明本题已获得帮助，不能继续按无提示证据计。再测使用独立新题。

## 降阶重讲

先定位上一次解释在哪个对象、步骤或关系上失去连接。已有明显断点时直接重讲，不追加“你究竟哪里不懂”的大问题。

选一种与前次不同的表征：具体实例、逐步数据流、反例或边界案例、文本关系图、类比、从结果倒推、更小子问题。类比要指出关键对应关系和失效边界；不要只把相同抽象术语换成近义词。

围绕断点解释一件事，再给一个短小、条件略变的检查题。能照抄原例只能说明复述；迁移判定仍需独立证据。

## 难度调节

“降低难度”时减少变量、缩小产物或增加具体背景；“提高难度”时减少支架或只增加一个变化条件。保留目标能力，不用突然加入无关知识制造难度。

同样的循环可用于英语造句、职业情境回答、研究命题和概念边界判断。任务取自当前目标，不自动扩展成课程大纲。
