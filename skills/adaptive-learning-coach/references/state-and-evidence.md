# 状态与证据

读取条件：读取当前进度、判定或记录能力、暂停接续，或处理术语冲突。

## 状态来源与写入

按以下顺序选择单一状态来源：

1. 项目明确指定的进度文件。
2. 已存在且与当前学习有关的状态文件。
3. 当前对话中的可见状态。
4. 用户明确要求创建后，才新建状态文件。

先读当前进度；稳定教学约定仅在本轮需要时读取，旧课程和历史手册仅用于填补具体证据缺口。附件里无法解析的引用标记不是文件路径；缺失时说明无法读取，并只询问所需材料的位置。

形成实质进展后先整理状态增量。当前用户请求或项目授权已覆盖该文件更新时，增量更新相关段落并保留无关内容；不重复确认已有授权。没有写入授权时在对话中给出待写增量，只有确实需要持久化才请求授权。文件存在本身不等于有写权限。

“暂停并记录”意味着停止新任务并压缩状态；无既有状态文件且未要求建文件时，将接续块留在对话中。禁止为了接续自动创建每课文件、第二套进度、词典、CONTEXT.md 或 ADR。

## 能力判定

每条证据绑定**具体任务与条件**。分别记录：任务是否完成、答案正确性、帮助程度、因果解释、迁移表现；没有观察到的维度写“未观察”，不从“运行通过”“看懂了”或代理完成的结果推断。

| 能力状态 | 判定依据 |
|---|---|
| 未观察（Unobserved） | 没有学习者实际表现；包括只看过代理答案或演示 |
| 带提示完成（Assisted） | 学习者实际完成，但本任务用过解题提示或示范 |
| 独立完成（Independent） | 本任务达到标准，关键判断由本人完成；允许资源内查文档或用工具不自动失去独立性 |
| 迁移成功（Transfer） | 条件发生实质变化后，学习者仍能独立调整并验证 |
| 待复测（Retest Needed） | 曾经完成，但有遗忘迹象、关键条件变化、重复表现不稳定，或证据时效不足 |

同一任务记录用过的最高 H 等级，等级含义见 [teaching-loop.md](teaching-loop.md) 的提示阶梯。H1—H4 下完成不能标为独立；完整方法或答案为 H4，代理交付后学习者尚未表现仍为未观察。H0 本身也不证明成功，错误或未完成必须原样记录。

答案已经泄露的原题不能通过“重做一次”洗成 H0。相近新题或变式需单独记录提示与表现；新题独立成功不抹去原题协助历史。复述可证明部分理解，迁移必须有改变条件后的独立表现。

能力状态只描述这项能力在这些条件下的证据，不是永久标签。数日后接续先查看旧证据，不仅因经过几天就判定遗忘或重做全套评估；必要时用一个小任务复测。

## 跨领域证据

| 领域 | 当前表现 | 迁移证据 |
|---|---|---|
| 编程与工程 | 运行结果、测试、修改、调用链或失败路径解释 | 改变输入、接口或约束后独立调整与验证 |
| 英语 | 听辨、复述、造句、场景回答；文字回复不能证明听力或发音 | 新场景下独立组织正确表达 |
| 投资研究 | 命题、可追溯证据、反证、失效条件；单次回测盈利不证明稳定 Alpha | 新数据下独立修正命题和验证依据 |
| 职业训练 | 简历产物、模拟任务、面试回答及理由 | 面对新岗位或追问独立重组表达 |
| 一般概念 | 自己解释、举例、判断边界 | 在陌生问题中正确使用并解释 |

记录证据是谁产生的：学习者回答、代理运行、用户报告、静态推断、模拟数据分别注明。用户报告的结果可以保留，但不能冒充已亲自验证。

## 术语

专业概念首次出现用“中文名称（English term）：一句底层机制＋当前任务实例”，沿用项目的规范叫法。出现冲突时指出两个词义并用具体对象或边界案例澄清；不能擅自改写项目定义。

仅在三个以上术语将反复使用、用户／代码／文档叫法冲突，或歧义已导致错误判断时，在现有状态中维护“关键术语”区；写入仍遵守本文件的授权规则。其余术语随解释给出即可。

## 最小接续块

只保留本轮新增或更正的信息、证据出处与下一步；能通过路径找到的代码和材料不抄写全文。

```text
当前目标：能力、产物、通过标准与限制的最小摘要
本轮证据：日期或轮次、任务条件、产物或路径、产生者、结果
能力状态与协助程度：具体能力；任务完成/正确性/最高H/因果解释/迁移
仍未解决：证据缺口、卡点、未验证假设；没有则写无
下一步最小动作：一个动作及通过条件；暂停时仅供下次接续
相关材料：现有状态、约定与目标材料的路径或链接
```

信息不足就明确不足，不为填满模板推测经历；无新证据时不重写状态。接续时以这一小块恢复任务，不要求用户复述背景。
